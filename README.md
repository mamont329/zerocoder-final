# FinControl

Сервис учёта личных финансов: веб-интерфейс на Django и Telegram-бот.
Позволяет вести доходы и расходы, смотреть аналитику по категориям и периодам,
получать советы и предупреждения о превышении лимитов.

## Стек

- Python 3.13, Django 6.1
- SQLite
- pandas, plotly — аналитика и графики
- aiogram — Telegram-бот
- Bootstrap — вёрстка

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS

pip install -r requirements.txt

cp .env.example .env            # и заполнить SECRET_KEY
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/, админка: http://127.0.0.1:8000/admin/

## Структура

| Путь | Назначение |
| --- | --- |
| `fincontrol/` | Настройки проекта, корневые URL |
| `finance/` | Приложение учёта финансов: модели, формы, представления, шаблоны |
| `finance/periods.py` | Периоды отчётности — общие для веба, аналитики и бота |
| `finance/analytics.py` | Агрегаты, аномалии и советы — без привязки к вебу |
| `finance/charts.py` | Построение графиков plotly |
| `docs/` | Техническое задание |

## Разделы сайта

| Адрес | Что делает |
| --- | --- |
| `/` | Сводка: доходы, расходы и баланс за месяц, последние операции |
| `/operations/` | История операций с фильтрами по периоду, типу и категории |
| `/analytics/` | Аналитика: динамика по времени, структура расходов, лимиты, советы |
| `/categories/` | Категории пользователя: создание, изменение, удаление |
| `/accounts/login/`, `/accounts/signup/` | Вход и регистрация |
| `/admin/` | Админка Django |

## Аналитика

Графики строятся на plotly, агрегаты — на pandas. Палитра выбрана так, чтобы
серии различались при дальтонизме: доход — синий, расход — оранжевый
(привычная красно-зелёная пара для этого наименее пригодна). На кольцевой
диаграмме не больше пяти категорий, остальные сворачиваются в «Прочее», а
полный список всегда есть в таблице рядом.

Аномалией считается рост расходов по категории в 1.5 раза и минимум на 500 ₽
относительно среднего за три предыдущих периода той же длины.
